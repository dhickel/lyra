# Reference map

Use these documents when you need an exact rule rather than a guided task.

## Language

- [Formal language specification](../specification/language.md) defines current syntax, static semantics, evaluation, modules, and language failures.
- [Complete language and product reference](../reference/index.md) provides lookup pages for language forms, CLI commands, artifacts, Java APIs, the REPL, and the editor.
- [Readable grammar](../../lyra-compiler/src/main/resources/grammar_spec.md) gives the concrete EBNF used as a synchronization aid. The formal language specification takes precedence.
- [Deferred feature reference](../reference/deferred-features.md) identifies features and spellings outside the current language.

## Product guides and evidence

- [REPL and attachment guide](../repl.md) is the detailed operational guide for local sessions, reload, attachment, protocol behavior, and limits.
- [Editor guide](../editor.md) is the detailed workspace, run, REPL, debugger, file-safety, and packaging guide.
- [Language testing guide](../language-testing.md) maps current language behavior to executable corpus and fuzz coverage.
- Run `lyra --help` for the exact installed command surface.

The learning pages summarize verified behavior but do not replace the formal specification or lookup reference.
