## Behavioral Impact

Intrinsic calls use explicit immutable environments, deterministic encoding and serialized writes/flushes, blocking input with UTF-8/BOM/CRLF/EOF handling, structured `LYR-IO` failures with interruption preservation, owner/lifecycle checks before stream access, independent artifact environments, and non-owned caller streams.

## Specification Impact

Specification Impact: none. The implementation follows the existing Phase-20 `std->io` identity, direct-lowering, I/O, failure, and stream-ownership contract.

## Risks

Compiler-only focused Maven tests require a freshly installed runtime snapshot after runtime source changes; reactor builds avoid this dependency-state hazard. Bundled executable packaging and CLI launch remain later-phase work.

## Follow-up Items

Phase 21 must integrate the exact `main`/CLI and launcher behavior without widening the intrinsic I/O or stream-ownership boundary.
