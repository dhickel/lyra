## Key Takeaways
- Use independent `BigInteger` range arithmetic and an explicit widening-domain table as test oracles. Reusing compiler folding, type-conversion predicates or emitted runtime helpers would reproduce their defects in the expected result.
- F32 operations round at each node. Unary negation must preserve IEEE signed zero; modeling it as `0 - value` loses that distinction. A complete F64 expected context can widen F32 operands before arithmetic, so the oracle must match the source contract used by the test.
- Unsigned Java inputs are raw same-width bits. Normalize U8/U16 before integer-to-floating division/reciprocal. U64 multiplication overflow checking uses `Long.divideUnsigned(JJ)J`, followed by `Long.compareUnsigned(JJ)I`; sharing their descriptors produces invalid bytecode.
- For high-bit U64-to-float conversion, converting the low 63 bits and adding 2^63 can round twice. Halve with an unsigned shift, preserve the discarded low bit as a sticky bit, convert directly to the requested F32/F64 precision, then multiply by two. Seed 42 exposed `16092878570068704171U64 -> F64` rounding one ULP too high; permanent tests cover that value, both rounding-tie parities, adjacent values and thousands of independent BigInteger expectations.
- Then-only conditionals discard the selected branch's value and return Unit. Both ordinary expression and function-tail lowering need that rule. Unit-typed tail branches must still retain self-tail-call lowering; a blanket discard path would reintroduce stack growth.
- Canonical fresh allocation IDs must include allocations referenced only by ownership requirements, not just returned values, writes and call arguments. A local immutable array aliased through an `@mut` binding can otherwise fail before emission.
- Parentheses represent callable application, not a general grouping expression, except that an exact `(::f[])` wrapper now preserves that direct call. Adding another child, as in `(::f[] extra)`, still invokes the direct call's result. `(f)` invokes a zero-argument callable. A following `::` can extend the preceding expression as a member call despite whitespace; use commas only at the narrow accepted sibling boundaries.
- The public source String API requires well-formed UTF-16. Mutation operates on code points; arbitrary bytes go through `SourceSnapshot.capture` and are checked against a strict independent UTF-8 decoder. Escape spellings such as `\uD800` still exercise legal lone Char surrogate values.
- Session observation submissions also consume the default 256 retained source records. Long model histories must reset every 20-step operation cycle; a refusal carrying the existing session `LYC-EMIT-001` source-registry diagnostic is expected budget enforcement, not an ordinary compiler emission defect. The campaign checks budget refusal and reset recovery separately.
- Targeted REPL-only reactor commands need a compiler test selector too because the compiler module has `failIfNoTests=true`. Include `LanguageCoverageTest` alongside `SessionStateFuzzTest`; `surefire.failIfNoSpecifiedTests=false` alone does not bypass that module policy. A combined extended campaign can use `-pl lyra-repl -am` so one invocation runs the runtime/compiler nominal matrix and the session model, and the reactor exit code covers both models.
- The compiler-side fuzz worker can drive a real retained session without the REPL: compile the producer via `LyraCompiler.compileSession`, load through `LyraRuntime.loadSubmission` + `prepareSubmission` + `executeSubmission`, register staged root bindings and nominal factories exactly like `LyraSession` does, and commit. Requirements come from `typedIr().declarations()` external bindings plus `sessionExecution().externalAccesses()`; factory requirements are `resolvedGraph().nominals()` minus the current generation's `IrNode.NominalDeclaration` forms. A failed `executeSubmission` publishes nothing and does not advance the domain revision; the next submission links at the same revision against the previous staged snapshot.
- Suffix every literal in retained observation expressions. Unsuffixed integer literals inside conditional branches can widen a `+` result to `I64`, so `readSubmissionResult(module, PrimitiveType.I32)` fails with a submission-result contract mismatch.
- Transfer-variant facts that differ from naive reading of the source: reading a `@mut` binding is `Apply[CONVERSION]` over a `Reference` (only immutable reads are plain `Reference`); `self:.x` is a routed `Reference`, not a `Project`; `holder::read[]` (call through a mutable member slot) is a `CallableCall`; `Project` covers indexed/length/string-index bases. `iter` is a reserved keyword, and a nominal member named `length` is captured by the built-in length access and fails with `LYC-EMIT-002` even in the same generation.
- The four issue-#7 Unit/intrinsic observation shapes (namespace direct call, namespace member, iter, while) are validated through the standalone `SessionStorageDomain` protocol and `LyraSession`, not only by one surface. They now observe exact Unit values across generations, preserve exactly-once construction effects, and invoke the namespace-member callable where applicable. The retained model keeps these as successful pinned inventory operations; raw imported closures and wrong routes remain structured failures.
- Retained `@mut` declaration reads re-resolve the current shared cell at construction time, so a factory that captures a mutable callable sees later rebinds; immutable declarations keep the original slot even when a later generation redeclares the same name (the `retainedFactoryReferenceSurvivesLaterLexicalShadowing` shape). Session-side member writes through a retained object require a mutable (`@mut`) binding; an immutable binding fails with `LYC-RESOLVE-021` (external binding does not authorize this assignment).
- Valid-source compiler invariants found while building the retained campaigns:
  indexing an `Array<@nil I32>` literal inside a retained member initializer crashed
  with `INCONSISTENT_SUMMARY: retained projection route/index/result differs` while
  the ordinary compile path accepted the same source; that crash was fixed in phase 4
  (the routed-type comparison no longer strips nilability, which is stricter, and
  consumer-side composite prefixing is handled by a prefix-aware nil-route walk), and
  the `nilable-index` generator operation now covers it. The reported direct-rebind
  crash (`retained rebind value/result type differs` for a top-level mutable rebind
  inside a member initializer expression) did not reproduce in any legal probe shape
  during that fix round, so no generator exclusion is required for it.
- The session state model now rotates twenty operations. Reset unconditionally at the reset op (every 20-step cycle): with a 12-op cycle the `step % 24 == 23` alignment made reset land on the reset op, but a 20-op cycle breaks that alignment and the 256-record source registry overflows (revision ~350 with only random resets).
- The retained campaign summary is the driver-side guard: `summary.txt` carries `retained.ops=<total>` plus one `retained.op.<name>=<count>` and `retained.profile.<name>=<count>` line per name. `LanguageFuzzTest.validateSummary` fails the bounded default run on a zeroed total, a missing operation, or a missing profile; the minimum 120-case budget per seed covers all ten profiles and all operation names, and the worker cross-checks executed operations against the deterministic model rotation inventory.
- Loop fuzz sources must render negative range bounds/steps as unambiguous unary expressions such as `(- 0 18)`. Concatenating a bare negative spelling directly with `..`/`...` can produce malformed range tokenization (for example `-18...-4:-2`) even though the independent traversal oracle is valid.
- Save checkpoints before execution and kill entire child workers on timeout. Thread interruption alone cannot stop arbitrary parser/compiler recursion. Do not initialize artifacts generated by unconstrained mutations.

## Project Relevance
These tests are selected by ordinary `mvn test`. Feature changes must update positive/negative/boundary fixtures, fuzz generators and independent expectations, inventory guards and the developer coverage matrix. A passing campaign is evidence for the tested contracts; worker resource limits do not add production sandboxing or authentication. The retained-nominal compiler family and the extended session rotation now exercise the cross-generation transfer/certificate algebra and its runtime linkage in every bounded and extended run; any change to the retained algebra, the session storage domain protocol, or the nominal runtime must keep every operation name, profile, and successful Unit/intrinsic inventory case in that rotation. Explicit test selectors must exclude all fuzz tests outside the final qualification gate; never use an unfiltered module-scoped Maven command when a prohibited fuzz class may be selected.

## Open Questions
None required for the current suite. Coverage-guided instrumentation and production isolation are separate future work, not capabilities claimed by these generational/mutation campaigns.
