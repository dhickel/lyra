## Key Takeaways
- Use independent `BigInteger` range arithmetic and an explicit widening-domain table as test oracles. Reusing compiler folding, type-conversion predicates or emitted runtime helpers would reproduce their defects in the expected result.
- F32 operations round at each node. Unary negation must preserve IEEE signed zero; modeling it as `0 - value` loses that distinction. A complete F64 expected context can widen F32 operands before arithmetic, so the oracle must match the source contract used by the test.
- Unsigned Java inputs are raw same-width bits. Normalize U8/U16 before integer-to-floating division/reciprocal. U64 multiplication overflow checking uses `Long.divideUnsigned(JJ)J`, followed by `Long.compareUnsigned(JJ)I`; sharing their descriptors produces invalid bytecode.
- For high-bit U64-to-float conversion, converting the low 63 bits and adding 2^63 can round twice. Halve with an unsigned shift, preserve the discarded low bit as a sticky bit, convert directly to the requested F32/F64 precision, then multiply by two. Seed 42 exposed `16092878570068704171U64 -> F64` rounding one ULP too high; permanent tests cover that value, both rounding-tie parities, adjacent values and thousands of independent BigInteger expectations.
- Then-only conditionals discard the selected branch's value and return Unit. Both ordinary expression and function-tail lowering need that rule. Unit-typed tail branches must still retain self-tail-call lowering; a blanket discard path would reintroduce stack growth.
- Canonical fresh allocation IDs must include allocations referenced only by ownership requirements, not just returned values, writes and call arguments. A local immutable array aliased through an `@mut` binding can otherwise fail before emission.
- Parentheses represent callable application, not a general grouping expression. `(::f[])` calls the result of the direct call; `(f)` invokes a zero-argument callable. A following `::` can extend the preceding expression as a member call despite whitespace. Use ordinary callable syntax or real argument/form boundaries in fixtures.
- The public source String API requires well-formed UTF-16. Mutation operates on code points; arbitrary bytes go through `SourceSnapshot.capture` and are checked against a strict independent UTF-8 decoder. Escape spellings such as `\uD800` still exercise legal lone Char surrogate values.
- Session observation submissions also consume the default 256 retained source records. Long model histories must reset or deliberately configure capacity. A refusal carrying the existing session `LYC-EMIT-001` source-registry diagnostic is expected budget enforcement, not an ordinary compiler emission defect. The campaign checks budget refusal and reset recovery separately.
- Targeted REPL-only reactor commands need a compiler test selector too because the compiler module has `failIfNoTests=true`. Include `LanguageCoverageTest` alongside `SessionStateFuzzTest`; `surefire.failIfNoSpecifiedTests=false` alone does not bypass that module policy.
- Save checkpoints before execution and kill entire child workers on timeout. Thread interruption alone cannot stop arbitrary parser/compiler recursion. Do not initialize artifacts generated by unconstrained mutations.

## Project Relevance
These tests are selected by ordinary `mvn test`. Feature changes must update positive/negative/boundary fixtures, fuzz generators and independent expectations, inventory guards and the developer coverage matrix. A passing campaign is evidence for the tested contracts; worker resource limits do not add production sandboxing or authentication.

## Open Questions
None required for the current suite. Coverage-guided instrumentation and production isolation are separate future work, not capabilities claimed by these generational/mutation campaigns.
