# Horizon Ideas

Record possible future direction that has not been accepted as a commitment.

## Future editor and debugger integration

Managed documents, source synchronization, LSP/completion APIs, structural editing, breakpoints, stepping, watchpoints, persistent debugger pause/resume, and latest-binding/state-migration reload remain unaccepted future direction. The current REPL contract accepts only passive source-origin metadata and bounded console completion; these future capabilities require separate specifications.
